# 新光銀行 靈活回復理財房貸（隨借隨還）清償期程計算器
### Shin Kong Bank Revolving Mortgage Payoff Calculator

一套專門針對**新光銀行「靈活回復隨借隨還（理財型房貸）」**設計的即時試算網頁工具。本專案以實際網銀對帳單的真實帳務結構為基準，破解「**每月只還最低利息卻永遠還不到本金**」的盲點，並提供視覺化圖表、不同還款額度比較與逐期攤還明細匯出功能。

## 📌 背景與痛點分析（實例還原）

在傳統一般分期房貸中，每月繳納的房貸包含「本金＋利息」（本息均攤）；而在**理財型（隨借隨還）房貸**中，銀行採**按日計息、不動用不計息、動用部分隨借隨還**：

### 真實帳務數據
- **核定循環總額度**：NT$ 3,500,000 元
- **當前透支餘額（本金）**：NT$ 3,484,687 元
- **實質適用年利率**：3.15%（透支按日計息，每月 21 日結算扣繳）
- **每日產生利息 (日息)**：$\approx NT\$ 300.7$ 元
- **每月利息支出**：約 NT$ 9,147 ～ NT$ 9,621 元（依當月天數而定）

### 🚨「無限循環利息陷阱」
若借款人每月僅於 19 日存入 **$9,200 ～ $9,300** 元：
1. 每月 21 日結算的透支利息就已達 **$9,046 ～ $9,621** 元。
2. 存入款項 **99%～100% 全被利息抵消**，甚至在 7 月（31天）利息達 $9,621 時，負債還倒增 $321 元。
3. **結論**：若每月僅還款 $9,200 元，將陷入**無限期只繳息不還本**的循環，**實質上永遠無法清償**！

## ✨ 系統功能與特色

1. **實體帳務一鍵還原**：預載實際負債本金 `$3,484,687` 與實際利率 `3.15%`，隨時可一鍵還原預設。
2. **直覺滑桿與自訂輸入**：支援滑動與輸入框雙向同步，自由微調每月還款預算。
3. **隨借隨還單筆大額試算**：支援模擬隨時投入獎金/分紅（如單筆償還 10 萬、20 萬），即時計算省下之利息與縮短年限。
4. **防呆與利息陷阱警示**：若每月還款 $\le$ 當期利息，系統主動跳出警訊提醒，避免無效攤還。
5. **Chart.js 動態走勢圖**：視覺化呈現本金歸零曲線與預估清償年份。
6. **分期明細與 CSV 匯出**：可檢視前 24 期、前 5 年或全期數明細（含每期利息、扣除本金、本金餘額），並支援一鍵匯出帶 UTF-8 BOM 格式的 CSV 檔案。
7. **單一檔案 (SPA) 架構**：無須後端伺服器或 Node.js 建置環境，雙擊 `index.html` 或透過 GitHub Pages 即可直接運行。
